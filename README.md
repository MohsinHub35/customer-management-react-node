# customer-management-react-node
# Customer Management App

## Tech Stack
- React JS
- React Router
- Node.js
- Express.js
- SQLite

## Features
- Create, Read, Update, Delete Customers
- Add Multiple Addresses per Customer
- Search Customers by City, State, Pin Code
- Simple Routing using React Router

## Run Locally


### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm start
